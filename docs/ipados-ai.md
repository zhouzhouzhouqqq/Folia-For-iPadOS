# iPad 自定义 AI 接口与原版主题分析

更新：2026-10-16。iPad 已加入个人 AI 直连，**无需部署 Folia API，也不依赖 Mac 常开**。每位源码侧载用户填写自己的服务地址和个人 Key。没有内置共享 Key 或公共 AI 服务器。

## 更新与配置

本次新增 `FoliaAI` Swift 插件；仅重载页面无法更新原生代码。

1. 在现有工程目录运行 `npm run ios:sync`（交付时已执行）。
2. 用 Xcode 打开 `ios/App/App.xcodeproj`，选择 `App` scheme 和实体 iPad，沿用原来的 Team/Bundle Identifier，按 ⌘R 覆盖安装。不要删除原 App，以免丢失本地数据。
3. App「设置 → 连接与集成 → 自定义 AI 接口」。也可在命令面板搜索「自定义 AI 接口」。此设置只在原生 iOS 中显示；桌面仍用原来的桌面 AI 设置。
4. 选择 OpenAI Compatible，填写服务商提供的 HTTPS **Chat Completions** 地址、模型 ID 和个人 API Key。保存后可以点击「测试已保存的连接」。
5. 「设置 → 外观 → 主题生成来源」选择「AI 推断」。返回歌曲，使用原版「生成 AI 主题」操作或同名命令。首次将歌词交给目标服务前有文本传输确认。
6. 生成后沿用原版主题缓存、明暗切换、自动应用及外观导入导出。若当前优先使用自定义主题，需切回 AI 主题才会看到变化；缓存主题可继续复用。

不要将 Key 发给他人或粘贴进聊天。保存配置本身不发网络请求。测试发送固定 `hello`，可能产生服务商费用；生成主题/分词也可能计费，按服务商规则执行。

## 地址与模型

- `https://你的服务域名` 自动补成 `/v1/chat/completions`。
- `https://你的服务域名/v1` 自动补成 `/v1/chat/completions`。
- 带其他前缀时，应填写服务商给出的完整 Chat Completions 路径。
- 不接受 HTTP、URL 内账号密码、查询参数或 fragment。认证使用原生注入的 Bearer Header；不关闭 TLS 校验，不添加全局 ATS 豁免。所有 HTTP 跳转均拒绝，应填写最终 HTTPS 地址。
- 模型 ID 使用服务商的实际名称。本适配不新增模型清单或承诺接口存在。留空时沿用源码既有默认值（官方 OpenAI 为 `gpt-5.6-luna`，DeepSeek 为 `deepseek-v4-flash`），这些名称在具体账号是否可用仍需用户核实，建议显式填写。
- 仅支持原版 Chat Completions 协议及其原有字段协商；不把 Responses API、任意自定义认证或其他服务格式视为兼容。
- Google Gemini 沿用原版固定端点和 `gemini-3-flash-preview`，仅需 Key；本次没有更换其模型。地区、网络、模型下线和权限限制仍由服务商决定。
- Temperature 和 SSE 开关沿用原版兼容接口语义；某些模型拒绝 Temperature 时，使用原有参数协商。iPad 原生侧有界收齐 SSE 后，交由原版 SSE 解析器处理，再一次性应用主题；不声称逐 token 预览。

## 分析内容和原版范围

原桌面 `electron/main.cjs` 的主题提示词与 schema 对照测试保持一致，主题生成最多取前 2000 个 JavaScript 字符（源码 `slice(0, 2000)`，精确说是 UTF-16 单元），纯音乐使用现有标题路径。生成结果含：

- 明暗两套主题名称、情绪描述；
- 背景、主文字、强调、次要元素的配色；
- 情绪词 `wordColors`；
- Lucide 歌词图标 `lyricsIcons`。

字体默认 sans、动画强度默认 normal，之后应用用户已保存的强度偏好。原版此接口**没有让模型生成任意着色器、所有背景数值或完整动画配置**；本次按实际输出合同保留，未扩大模型能力的宣称。全部已有动画和背景 renderer 继续使用现有代码与用户参数。

同一配置也供原版「AI 分词」使用，沿用原提示词、100 行分批、推理关闭协商、行对齐和部分失败处理。手动复制提示词/粘贴主题 JSON 的路径继续保留。

## 凭据、传输与清除

个人 Key 在输入时短暂经过页面表单，保存后清空输入框；后续读取仅返回 hasKey 和非秘密配置。Key 与配置存于安装独立的 iOS Keychain（AfterFirstUnlockThisDeviceOnly，不同步）。Key 不放在 localStorage、IPA、源码包、外观配置或主题同步数据中。App 更新且签名标识保持一致时可继续读取；删除/重装、签名/Bundle Identifier 改变后的恢复不保证。

留空 Key 仅可沿用相同 provider 和完全相同规范化 endpoint 的旧 Key。更换地址必须重新输入，防止旧密钥自动发往另一个服务器。原生只允许请求已保存的确切 endpoint 和配置 revision；不接收任意鉴权 Header，不带浏览器 Cookie，不跟随重定向。每次请求最大正文 1 MB、响应 4 MB、资源期限 125 秒，最多 4 个并发请求，可取消；保存/清除时取消旧请求。超限显示错误，不静默降低歌词特效。

歌词/标题直接流向所选 AI 服务，该服务若是中转站可能继续转发给其模型供应商。会话内首次按目标 origin 确认，拒绝则不发送。不会上传音频、封面、账号 Cookie 或本地个人文件。没有执行真实付费调用。

「清除 AI 配置和 Key」会移除此安装的凭据；已生成主题缓存继续由原有主题管理控制。清除后若配过 Folia 后端，将回到原有后端路径。没有个人 Key 时也保留可选 `/api/generate-theme*`、`/api/segment-lyrics` 后端模式；服务端私有 Key 继续只在服务器环境变量中。

## 故障排查与验证范围

- 找不到入口：确认运行的是包含本次 Swift 插件的新原生 App，使用 ⌘R 覆盖安装；在「连接与集成」，不是桌面设置。
- 无法读取原生 AI 设置：检查 Xcode 中 AIConfiguration.swift、AIService.swift、FoliaAIPlugin.swift 已进入 App target 并注册插件；仅热更新网页资源不足。
- 测试按钮不可点：需要先保存 Key；有未保存修改时测试禁用，避免误测旧地址。
- 401/403：检查 Key、账户权限、地区和服务商可用性。不会绕过限制。
- 404/跳转拒绝：检查是否为最终 Chat Completions 路径。不要填写控制台网页或 API 文档 URL。
- 测试成功但回复为空：可能是模型只产生推理或预算耗尽；UI 会注明。连接成功不代表结构化主题生成成功。
- JSON/主题失败：模型需遵循原版双主题输出合同；选能遵循 JSON 的模型。没有将静态主题伪装成成功的 AI 结果。
- 网络超时：检查 iPad 自身能否访问服务域名；不是 Mac 的联网状态。后台挂起期间不保证 AI 请求继续执行，建议在前台等待生成。

实际自动验证结果见 `ipados-test-report.md` 最新 AI 一节和 `ipados-validation/ai-direct-*`。已覆盖原引擎回归、原生模拟传输、WebKit 模拟桥、Web/PWA、Capacitor 同步、真实 iphoneos SDK arm64 无签名编译；这些不替代实体 iPad、真实 Key/模型、登录网络环境和生成质量验证。未验证所有第三方网关兼容性。

真机待办：更新后确认入口，保存后重启恢复，hello 测试，歌词/纯音乐生成明暗主题、词高亮及图标，切换动画强度，缓存/重新应用，拒绝授权无请求，更换地址需重输 Key，清除，网络失败/超时/切后台。播放与后台音频仍按独立专项清单验证，本次 AI 成功不代表此前播放问题已通过真机复验。
