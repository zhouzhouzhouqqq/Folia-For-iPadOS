# iPadOS 公开分享准备与在线后端边界

更新：2026-10-16。用户已选择公开源码、由每位用户自行签名安装，不上商店。最新要求是像 Mac 一样无需部署网易云 API：已改为设备内直连，停止 Vercel/共享后端路线。没有部署云服务、使用托管账号、发布仓库、上传 IPA、提交或推送代码。

## 默认无需网易云公共服务

桌面原来随应用运行 Node 增强 API；当前 iPad 使用 Swift 请求/加密/Keychain 加上复用的前端参数模块，在各自设备直连网易。无需运营共享网易后端，各用户的设备会话分别保存。详见 [实现和验证边界](ipados-netease-direct.md)。

公开源码的安装者仍需自行签名、在手机音乐 App 中自行扫码，账号权限/会员/版权与地区限制不变。歌单订阅 Watchman、NCBL 上报尚未实现，实际账号/所有效果/后台仍须真机验收。不能宣传与所有桌面功能完全相同。

QQ/酷狗/波点、AI/同步/外部集成目前仍有服务配置要求；[可选部署说明](ipados-api-deployment.md) 保留作为这些功能及用户主动选择远程网易覆盖时的说明，不是网易云登录的必经步骤。若将来选择共享托管，需另行授权部署并验证账号隔离、日志去凭据、访问控制与费用；本轮没有执行。

## 已选择公开源码、自行签名

| 渠道 | 对普通用户的要求 | 当前缺失 |
|---|---|---|
| 公开源码、自行签名 | 每位用户用Mac/Xcode和自己的Apple签名安装 | 可整理源码与指南；没有公开仓库或release，未授权自动提交推送 |
| TestFlight公开邀请测试 | 用户安装TestFlight；发行者需Apple Developer Program；外部测试可能需审核，构建有有效期和人数限制 | 发行账号、App Store Connect记录、签名、隐私/审核材料、完整真机回归；不是永久发行 |
| App Store正式发行 | 普通用户通过商店安装 | 需用户改变此前不上商店的要求；开发者计划、审核和公开发行准备 |
| Ad Hoc | 发行者登记接收者设备并签名，受设备额度限制 | 适合已知设备集合，不能作为任何人无登记安装的通用渠道 |

直接公开IPA并不能让全球普通iPad用户直接安装。地区性替代分发需按地区、资格与Apple当前要求单独评估，不能假设所有用户都可用。个人免费Team不能通用于任意他人设备。

本次新增 `README-ipadOS.md` 作为分享包入口，以及 `dev/ipados/export-source.py` 生成排除依赖/个人配置并清理签名字段的源码ZIP。清理只作用于ZIP内容，不修改本机Xcode签名。生成包不包含.git历史，也没有发布到GitHub。

## 公开发行前必须完成

完整视觉/后台音频/账号与导出仍须按原真机清单验收；AutoMix两模型已接入本机运行、待用户安装模型及真机验收；任意Node/native模组、桌面离线/透明导出等尚未实现，公开页面须如实列出。Folium宿主目前运行可信JS且不验签，不能宣称沙盒安全或桌面模组全兼容。

沿用上游AGPL-3.0，公开分发时保留许可证、署名并提供对应修改源码。发行签名/商店条款与AGPL的具体兼容性需在确定渠道后核实，不能因为拥有Apple账号便称所有发行条件都已满足。没有把未实现功能包装成完整移植版。
