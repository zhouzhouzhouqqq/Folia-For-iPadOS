# iPadOS 功能审计与实施表

原始审计基线：Folia 0.7.19，commit `35db05ccef6065e868fab14f49b433c8344e9ca1`；独立分支 `codex/ipados-self-use`。更新于 2026-10-16。保留未提交修改，未提交、推送、发布或部署。

交付为可继续开发、可在 Xcode 选择个人签名的移植工程，**不是已经完成全功能真机验收的发行版**。资源打包在 App 内；Capacitor 8.5.3 / WKWebView + app-local Swift 插件；没有 Electron/Node iOS runtime、远程网站主界面、全局 ATS 例外或 TLS 绕过。

“适配类别”严格使用原样复用 / 需要适配 / 需要原生替代 / 平台不支持；“交付状态”描述当前完成度。**已实现并验证仅指注明的检查层级**；编译通过不能证明 WebKit 运行、后台连续播放、功耗或视觉等价。各项真机结果与失败反馈单独记录；“待真机”表示该项最新实现尚未通过设备验收。
